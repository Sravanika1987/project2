🚀 OPTION 2: Manual Steps

STEP 1: Create GitHub Repository
─────────────────────────────────
1. Open browser: https://github.com/new
2. Repository name: hospital-management-system
3. Keep it: Public
4. Do NOT check "Initialize with README"
5. Click "Create repository"

STEP 2: Open Terminal in Project Folder
────────────────────────────────────────
• Right-click in this folder
• Select "Open in Terminal" or "Git Bash Here"

Or navigate manually:
cd "c:\Users\SRAVANIKA\Downloads\hospital-management-system-fainal-main\hospital-management-system-fainal-main"

STEP 3: Add GitHub Remote
──────────────────────────
Replace YOUR_USERNAME with your actual GitHub username:

git remote add origin https://github.com/YOUR_USERNAME/hospital-management-system.git

Example:
git remote add origin https://github.com/john123/hospital-management-system.git

STEP 4: Push to GitHub
───────────────────────
git push -u origin main

You'll be prompted for:
• Username: Your GitHub username
• Password: Your Personal Access Token (NOT your GitHub password)

🔑 AUTHENTICATION SETUP
═══════════════════════════════════════════════════════════════════════════════

GitHub requires a Personal Access Token (PAT) instead of password.

To create a token:
1. Go to: https://github.com/settings/tokens
2. Click "Generate new token" → "Generate new token (classic)"
3. Give it a name: "Hospital Management System"
4. Select scope: ✓ repo (check the entire repo section)
5. Click "Generate token"
6. COPY THE TOKEN (you won't see it again!)
7. Use this token as your password when pushing

🐛 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Error: "remote origin already exists"
Solution: git remote remove origin
Then try adding remote again

Error: "Authentication failed"
Solution: Make sure you're using a Personal Access Token, not your password

Error: "Repository not found"
Solution: 
  1. Check the repository exists on GitHub
  2. Verify the URL is correct
  3. Make sure repository name matches exactly

Error: "Permission denied"
Solution: Check that you own the repository or have write access
